Rezein privacy policy

Last updated: 18 November 2026

This policy covers the Rezein Hub Android app and the Rezein ordering and point-of-sale service it connects to. Rezein is operated by Empatech Pte Ltd. Each shop that uses Rezein runs its own business on it. In this policy, "the shop" means the business a customer is ordering from or a tablet belongs to.

What Rezein Hub does

Rezein Hub runs on a shop's tablet. It keeps a connection to the shop's server, sends print jobs (receipts and kitchen tickets) to the shop's network printers, and, in the version installed directly from the shop's site (not the Google Play version), if the shop turns it on, passes sign-in codes that customers text to the tablet on to the shop's server. The Google Play version does not read text messages or notifications. Staff set it up once with a one-time enrolment code. The app has no user accounts, no advertising and no tracking.

Information the app handles

  • Device pairing information. The device name and the token that links the tablet to the shop's server. This is stored on the tablet and on the shop's server so the shop can see and remove the tablet.
  • Print job status. Whether each print job was completed or failed. This is stored on the shop's server.
  • Text messages (only in the version installed outside Google Play, and only if staff allow it). If staff grant the "read texts" permission, the app reads texts that arrive on the tablet's SIM and sends the sender's phone number and the message to the shop's server. The server uses it to check a customer's sign-in code. Staff can switch this off by removing the permission.
  • Message notifications (only in the version installed outside Google Play, and only if staff allow it). If staff grant notification access, the app can read the code from a chat message notification for the same sign-in purpose.
  • Phone number for sign-in. The number a customer signs in with, held on the shop's server for the sign-in and the customer's orders.

The shop's server also keeps what the shop's service needs to work: orders, menu, payments recorded, member credit and customer contact details the customer or the shop enters. That is described by the shop's own notices.

How information is used

Only to run the service: printing, signing customers in, and showing the shop its own orders and devices. We do not sell information, share it for advertising, or use it for analytics or profiling.

Sharing

Information is sent to the shop that the tablet or customer belongs to, and to the service providers we use to run the server and deliver messages, who handle it only for us. We do not share it with anyone else unless the law requires it.

Security and storage

The app talks to the server over an encrypted (HTTPS) connection. The enrolment token can be revoked by the shop at any time. Information is kept while the shop uses Rezein and as the shop's records require.

Your choices and deletion

Customers can ask the shop they ordered from to correct or delete their information. They can also write to us at the address below and we will pass the request on to the shop or act on it ourselves. Staff can unlink a tablet in the shop's Devices screen and remove its permissions in Android settings. Uninstalling the app removes the pairing token from the tablet.

Children

Rezein Hub is a business tool for shop staff and is not directed at children.

Changes

If this policy changes, we will post the new version on this page and update the date above.
